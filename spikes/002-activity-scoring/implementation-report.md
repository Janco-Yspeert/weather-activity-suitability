# Spike 002 implementation report

Status: IMPLEMENTED

## Changed

- Surf and ski sufficiency denominators now come from independently generated
  destination-local expected activity slots rather than returned provider
  records. Missing timestamps therefore remain missing evidence.
- `ForecastService` now supplies the resolved location's IANA timezone to the
  scoring boundary. Expected-slot generation follows the actual local period,
  including offset transitions, and retains repeated-hour occurrences.
- Below 70% coverage, surfing preserves only a complete contiguous two-hour
  opportunity and caps the result at `GOOD`; otherwise it returns `UNKNOWN`.
- Below 70% coverage, skiing evaluates complete contiguous four-hour blocks
  using block-local snow viability, applies the calibrated conservative mapping
  and snow cap, and otherwise returns `UNKNOWN`. Sufficiently evidenced no-snow
  prerequisite failure still takes precedence.
- Added visible regressions for truncated excellent evidence, positive partial
  fallbacks, gaps, sparse adverse evidence, surf fallback caps and best-only
  aggregation, the full block-local ski snow table, the exact 70% ski
  transition, partial warm/marginal snow handling, the independent no-snow
  veto, and repeated-hour DST slot continuity.

## Consequential implementation decisions

- Expected slots are generated by enumerating instants and formatting them in
  the destination timezone. This avoids both the original returned-record
  denominator defect and a disguised fixed-24-hour assumption. Aligned points
  carry their expected-slot position so continuity remains correct across
  skipped or repeated local clock hours.
- Partial ski candidates are scored independently with each block's median snow
  depth. Reusing a wider-day snow median would allow unobserved or unrelated
  hours to affect the bounded positive fallback.

## Unexpected implementation discovery

- The historical evaluator public feedback expected all truncated below-70%
  examples to be `UNKNOWN`. The later human-accepted calibration explicitly
  supersedes that behavior by permitting conservatively capped minimum
  opportunities. The implementation follows the accepted calibration while
  retaining `UNKNOWN` for incomplete, discontinuous, or merely adverse sparse
  evidence.
